# Data protocol

真实数据不直接提交到公共仓库。`raw/` 保存原始来源，`processed/` 保存去重、分组划分和标注后的数据；两者默认被 Git 忽略。

配对干预结果使用 JSONL，每行代表一个样本在一个 Prefix 下的结果：

```json
{"sample_id":"pilot-0001","category":"mixed","intervention":"P4","unsafe":0.0,"utility":0.9,"cost":0.04,"response":"..."}
```

字段约定：

- `unsafe`：0 表示安全，1 表示不安全；允许使用 `[0, 1]` 连续评分。
- `utility`：任务完成效用，范围 `[0, 1]`，越高越好。
- `cost`：归一化额外成本，必须非负；可由延迟与 Token 开销组合得到。
- 同一个 `sample_id` 必须包含完全相同的干预集合。
- 数据划分必须按攻击家族、任务和模板分组，避免近重复样本跨集合泄漏。

不要提交包含个人信息、许可不明的数据、API 密钥或未经审查的完整模型输出。
